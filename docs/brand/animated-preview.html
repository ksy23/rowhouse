Rowhouse — animated marks

Eight files: four animations, each with a reversed twin for dark grounds. Each is a self-contained SVG with internal CSS, so it animates as an <img>, as a CSS background, inline, or in an <object>. No JavaScript, no external anything.

every one rests in the real static logo · every one stops on prefers-reduced-motion
