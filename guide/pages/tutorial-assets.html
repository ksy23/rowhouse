The installed base

Colin keeps track of the generators his company has installed at customers' sites, and calls each customer before a warranty runs out. The Assets related list shows one account at a time and no dates in color. Here, every account's assets are a grid on its page and a tab in a list of all accounts, with warranties about to end in amber.

The goal

What you will build

Two grids, built on the Grid Admin tab. Account Assets shows assets: on an account's page, that account's; and as a tab under each row of Installed Base, a grid of accounts with each one's number of assets and earliest warranty end. One grid configuration does both jobs.

Skip the build

To go straight to using the grid, click the button below, then Build in the dialog: it builds Account Assets and Installed Base as steps 1 to 3 leave them, in a few seconds, while a spinner says which grid it is on. Then go on to step 4, which puts them on pages. The build steps are still the way to learn how a grid is made.

Build it · admin

1. The asset grid

You need the Rowhouse Grid Admin permission set, and Customize Application to save (see Give people access).

  1. Open the Grid Admin tab. Click the App Launcher, type Rowhouse, click the Rowhouse app, then the Grid Admin tab, and click New grid.
  2. Fill in the Grid tab:
    FieldValue
    Grid titleAccount Assets
    API nameAccount_Assets fills in by itself
    ObjectAsset (Asset)
    Sort byUsage End Date (UsageEndDate)
    On a record page, show the records whoseAccount ID (AccountId), on Account pages
    Create records with New is already selected: users can add assets as rows of the grid.
  3. Add the columns. Click Columns (1). Asset Name (Name) is already there. For each row below, click Add column, choose the field, select Edit where the table says so, and type the header where it gives one:
    FieldEditHeader
    Product ID (Product2Id)✓
    Serial Number (SerialNumber)✓
    Status (Status)✓
    Usage End Date (UsageEndDate)✓Warranty ends
    Select Edit on Asset Name (Name) as well. The Product ID column's Header box suggests Product, in gray.

2. Warranty colors

  1. Add three display rules. Click Display rules (0). For each row below, click Add display rule and fill it in:
    MeaningFieldConditionValueLookApplies to
    Warranty ends soonUsage End Date (UsageEndDate)BetweenTODAY in the first box, TODAY+90 in the secondAmber fillThe cell
    Warranty expiredUsage End Date (UsageEndDate)Less thanTODAYRed textThe cell
    RetiredStatus (Status)EqualsObsoleteGray textThe whole row
    TODAY and TODAY+90 are worked out each time the grid opens, so the colors move with the calendar. Between includes both ends.
  2. Save. Click Save. After a few seconds the editor reads the grid back: Columns (5), Display rules (3).

3. The account grid

  1. Start another grid. Click Grids at the top of the Grid Admin tab, then New grid, and fill in the Grid tab:
    Grid titleInstalled Base
    API nameInstalled_Base fills in by itself
    ObjectAccount (Account)
    Sort byAccount Name (Name)
  2. Add two columns: click Columns (1), then Add column twice, and choose Account Type (Type) and Industry (Industry). Leave Edit as it is: this grid is for reading.
  3. Add the assets as a tab. Click Child tables (0), then Add child table:
    GridAccount Assets (Account_Assets)
    Linked byAccount ID (AccountId) already chosen
    Tab labelAssets
    The same grid as on the account page, so its columns, colors and New come with it.
  4. Save. Click Save: Columns (3), Child tables (1).
  5. Count each account's assets. Click Columns (3), then Add child total column. The child table list already says Assets (Installed_Base_Assets), the grid's only one. Leave Count as it is and the Header empty: the column is headed Assets.
  6. Show the earliest warranty end. Click Add child total column again:
    Field column: the top list, the child tableAssets (Installed_Base_Assets) already chosen
    The list under itMin
    The list beside it, Choose a fieldUsage End Date (UsageEndDate)
    HeaderEarliest warranty end
  7. Save. Click Save: Columns (5).
Build it · admin

4. The pages

  1. Put the asset grid on the account page. Open any account, click the gear at the top right, then Edit Page. Search the components for Rowhouse, and drag Rowhouse Grid onto the page, above the Related and Details tabs. On the right, enter Account_Assets in Grid Configuration. Click Save; if Salesforce asks, click Activate and assign the page as the org default for desktop and phone, as in Contacts on an account page.
  2. Give the account grid a page. In Lightning App Builder, click New, choose App Page, enter the Label Installed Base, choose One Region, drag Rowhouse Grid onto it, and enter Installed_Base in Grid Configuration. Click Save, then Activate; choose Sales, click Add page to app, then Save.

  1. Open the account. Open Grand Hotels & Resorts Ltd.
    The Account Assets grid is on its page, with no rows yet, and a New button above it.
  2. Add the first generator. Click New. A row appears at the top, with New where a row number goes. Fill in its cells, double-clicking each:
    Asset NameLobby standby generator
    Producttype Diesel 200, then choose GenWatt Diesel 200kW
    Serial NumberGW-200-4471
    StatusInstalled
    Warranty endsin the calendar, click Next Month once, then the 15
    The Save bar says "1 new record, 5 unsaved changes", and the row's cells are yellow: unsaved.
  3. Add the second. Click New again, and fill in the new row:
    Asset NameKitchen generator
    Producttype Propane 100, then choose GenWatt Propane 100kW
    Serial NumberGW-100-2093
    StatusInstalled
    Warranty endsclick Previous Month once, then the 15
    This one came secondhand, with its warranty already over. The new row goes under the first.

    2 items, in order of warranty end: the kitchen generator first, its date red because it has passed; the lobby generator's date amber, because it falls within the next 90 days. Both assets belong to Grand Hotels & Resorts Ltd: the grid knows which account's page it is on, so you never chose the account.
Use it · Colin

6. Review the installed base

  1. Open the grid. In the Sales app, click Installed Base.
    Every account. Grand Hotels & Resorts Ltd has a toggle with 2; its Assets column says 2 and Earliest warranty end shows the kitchen generator's date. Accounts with no assets have no toggle and say 0.
  2. Open the account. Click the toggle beside Grand Hotels & Resorts Ltd.
    One tab, Assets (2), the same grid as on the account's page: the same columns and the red and amber dates. Its own search and a ▾ menu sit at its top right.
Use it · Colin

7. Replace a generator

The hotel is replacing the kitchen generator rather than renewing its warranty. Colin records both, without leaving the list.

  1. Retire the old one. In the tab, double-click the kitchen generator's Status and choose Obsolete.
    The row's text turns gray at once: the Retired rule follows the unsaved value. Its expired date stays red; the date's own rule comes first.
  2. Add the new one. Open the ▾ menu at the top right of the tab and choose New. A row appears at the top of the tab; fill it in:
    Asset NameKitchen generator
    Producttype Propane 500, then choose GenWatt Propane 500kW
    StatusPurchased
    Warranty endsin the year list at the top right of the calendar, choose next year, then click the 15
    The panel's Save bar says "1 new record, 5 unsaved changes".
  3. Save the tab. Click Save in the panel's bar.
    The tab says Assets (3), and the toggle 3. The new generator's date has no color: it is more than 90 days away. It belongs to Grand Hotels & Resorts Ltd, the row the tab is under.
  4. Refresh the account grid. Click Refresh above the grid.
    The Assets column says 3. Totals on a row are worked out when the grid reads its rows, so a change saved in a tab shows there after Refresh.
Wrap-up

What you learned

{{ic:grid}}

One grid, two places

A record page grid can also be another grid's tab, with the same columns and rules.

{{ic:plus}}

New rows that know their parent

On a record page, or from a tab's ▾ menu, New fills in the record it belongs to.

{{ic:palette}}

Dates that move

TODAY and TODAY+90 keep the colors right every day.

{{ic:gauge}}

Min and count

Child totals put each account's asset count and earliest date on its row.
