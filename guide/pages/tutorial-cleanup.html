The contact clean-up, with an audit trail

Before every campaign, Caleb tidies the contact data: titles typed in lower case, missing lead sources, and a trade show's attendee list to add. Compliance wants to know who changed what, so this grid logs every change it makes.

Build it · admin

1. A grid that logs

  1. Create the Grid Configuration. In Setup, type Custom Metadata Types in the Quick Find box and click Custom Metadata Types. Beside Grid Configuration, click Manage Records, then New, and fill in:
    FieldValue
    LabelContact Cleanup
    Grid Configuration NameContact_Cleanup fills in by itself
    Object API NameContact
    Default Sort FieldLastName
    Default Sort DirectionAscending
    Allow Import✓ select it
    Log Changes✓ select it
  2. Save.
With Log Changes selected, a change that cannot be logged is not made either, so the log never has gaps. Everyone who uses this grid needs the Rowhouse Grid User permission set, which lets them write log entries but never edit or delete them.

The ninth column is a field of each contact's account: Account.Industry, written the way a report or a formula writes it. With no Column Label it is headed Account: Industry. Changing it changes the account, so an import, which changes contacts only, leaves it out.

  3. Save and activate, adding the page to the Sales app.
Build it · admin

4. Where the log is

Rowhouse comes with a tab for the log, Grid Edit Logs, in its own Rowhouse app. The Rowhouse Grid Admin permission set shows that tab; users of the grid see only the app's Grid Guide.

  1. Find the app. Click the App Launcher (the nine dots at the top left) and type Rowhouse. The Rowhouse app is listed under Apps, with the Rowhouse logo.
    Its navigation bar has three tabs: Grid Guide, Grid Admin and Grid Edit Logs. Nothing to set up; you come back here in step 8.
For your compliance team

Users read their own log entries; anyone else reads one only as your org's sharing allows. To let an auditor read everyone's, create a permission set of your own with View All on Grid Edit Log, and the Grid Edit Logs tab set to Visible, and assign it to them. Rowhouse does not ship one, so reading the whole log is always a deliberate grant.

Use it · Caleb

5. Tidy in place

  1. Open the grid. In the Sales app, click Contact Cleanup (under More if it is not in the bar).
  2. Find the messy titles. Click the Title header to sort by title, then look down the column for titles typed in lower case. (Sorting ignores case, so they sit among the others.)
  3. Fix one by typing. Click a lower-case title (we use vp sales, Molly Fitzgerald's) and just start typing VP, Sales. Your first letter replaces the old value. Press Enter.
  4. Fix another. Do the same for a second one (we change head of it to Head of IT).
  5. Fix an account's industry. Edge Communications is in telecoms, but its industry says Electronics. On any of its contacts' rows (we use Rose Gonzalez's), click Account: Industry, press Enter, choose Telecommunications and press Enter.
    Telecommunications, in yellow, on every Edge Communications row, Margaret Doucette's and Sean Forbes's too: it is the account's industry, so it changed once for all of them. The Save bar counts it as one change.
Use it · Caleb

6. Update many at once

  1. Select the contacts from the partner event. Select the checkboxes of the contacts with no Lead Source that came from a partner (we select Molly Fitzgerald, Ethan Hale and Walter Chandler).
  2. Set their lead source. In the bar over the grid, click Update field. Choose Lead Source, choose Partner Referral, and click Apply.
  3. Save. Click Save on the Save bar, then Clear in the selection bar.
    The changes are saved, and each changed value now has a log entry with its value before and after.
Use it · Caleb

7. Import the trade show's attendees

The attendee list comes as a spreadsheet. Its headers match the grid's columns, and its rows have no record Id, so each one creates a new contact.

  1. Get the file. Download event-attendees.csv (three attendees), or use your own list with the same headers.
  2. Start the import. Click Import above the grid (it is grayed out while you have unsaved changes) and drop the file onto the dialog, or click Choose file.
  3. Check the rows.
    Step 2 of 4: check the rows. Nothing has been written yet. Three boxes: 0 updates, 3 new records, 0 rows with problems; under Columns, each of the file's columns with the grid column it is imported as; and the three rows as they will be written. The Account column found each account by name.
  4. Import. Click Import 3 rows. When the dialog says "The import created 3 records.", click Close. The grid reloads with the three new contacts. (Before closing, Undo import would have deleted them again.)
How the Account column matched

A lookup in a file can be a record Id, or the name of a record already showing in the grid. Edge Communications, GenePoint and Express Logistics and Transport each already have contacts in this grid, so their names were enough. A name that matches no record shown, or two of them, is held back with the reason.

Use it · Caleb

8. Read the log

  1. Open it. Click the App Launcher (the nine dots), type Rowhouse, click Rowhouse, then the Grid Edit Logs tab. Choose the All list view.
  2. Read the columns. The All view shows each entry's Created Date, Created By, Operation, Record Name, Field Label, Old Value, New Value and Save Id.
    Six Update entries from your one save, sharing one Save Id: two for the titles you fixed, with the old and new value; one for the industry, named Edge Communications because it is the account that changed, from Electronics to Telecommunications; and three for Lead Source. Then three Create entries for the imported attendees, named after them, sharing the import's Save Id.
