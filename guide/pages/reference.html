  • Wrapped text shows up to three lines. Height (px) is at least 160, on a grid and on a child table. A filled grid is at least 240 pixels tall.
  • A chart names the nine largest groups and puts the rest in Other, or shows a date's last 24 periods and the ones before as Earlier; one chart per user per grid.
  • A grid file (Export and Import Grid on the Grid Admin tab) holds up to 50 grids, child grids included, and 2 MB.
  • Undo import works until the import dialog closes. It deletes only records you created in the last day.
  • More than 100,000 matching records: the grid opens as usual and shows how many match (10,000 of 110,000 items); it scrolls through the first 100,000, and a search or filter reaches the rest. Counts, group counts and subtotals cover every match. Tested with 110,000 records.
  • Subtotals are exact over every matching record. Over 45,000 records they are worked out in slices that the browser adds up; sums beyond about 15 significant digits are rounded by Salesforce.
  • With Log Changes on, one transaction writes at most 5,000 log entries, so saves and imports of very wide rows go in smaller batches.
  • Names in a paste or an import: up to 200 different names per lookup column are looked up in Salesforce at once. A name past that is held back; its record Id works instead.

The charts above were measured before the grid worked this way, so a first row now comes sooner than they show: in the same org, a grid of 56 rows and 16 columns has its rows about 0.4 s after it starts loading, against about 1.05 s before.

Make a grid faster

Fewer columns help most: 20 columns take roughly twice as long as 5 to load, sort and edit. A smaller Page Size shows the first rows sooner on slow connections. And a grid of an object with more than 10,000 records sorts and searches on the server, which is slower than sorting rows already in the browser.

Things people ask for that Rowhouse does not do.

Questions

Questions people ask

Can I undo after saving?

No. Undo covers changes you have not saved. Saved values are the record's; use the record's field history, or the grid's audit trail if your admin turned it on, to see what they were.

What if two people edit the same record?

The last save wins, as with a list view's inline edit. Rowhouse does not lock records while they are being edited.

Do my company's validation rules, triggers and flows still run?

Yes. A save from the grid is an ordinary save. If a rule refuses a record, its cell shows the rule's message and the other records still save.

Does any data leave Salesforce?

No. Rowhouse makes no callouts and loads no outside code. Export creates a file in your own browser.

Does it work in Salesforce Classic or the mobile app?

It runs on Lightning pages in Lightning Experience, and in a narrow space it switches to record cards. It does not run in Classic or in Experience Cloud sites, and it has not yet been tested in the Salesforce mobile app.

How does it show amounts when my org has more than one currency?

Each amount in its record's currency, by its code, as Salesforce does: USD 78,250.00, CAD 1,000.00. Totals and subtotals are in your org's corporate currency, each record converted at your org's rates, and show its code. Filters and display rules compare amounts as stored, in each record's own currency (Features › More than one currency).

Which browsers does it support?

The browsers Salesforce supports for Lightning Experience.

Why does New sometimes open Salesforce's New form instead of adding a row?

A row in the grid can be filled in only through the grid's own columns. When a new record needs a required field that is not an editable column, when you have more than one record type to choose from, or when the grid does not let you edit cells, New opens Salesforce's own form instead, with what the grid knows already filled in, such as the account on an account's page. The record you save there appears at the top of the grid.

Does a field's lookup filter apply in the grid?

Yes, when you edit the cell: a lookup with a lookup filter opens Salesforce's own lookup, which offers only the records the filter allows. A paste or an import matches a record by its Id, or by its name, looked up in Salesforce; if a required lookup filter rejects that record, Salesforce refuses it when you save, and the cell says why.

Words

Glossary

API nameThe name Salesforce uses for an object or field in code and settings, such as Opportunity, CloseDate or My_Field__c. Shown in Object Manager under Field Name.
Grid ConfigurationThe record that describes one grid, built on the Grid Admin tab or in Setup. Its API name goes into the Rowhouse Grid component.
Grid Admin tabWhere grids are listed, built, changed, cloned, exported, imported and archived without Setup, on its Grids page, and Rowhouse's own settings are made, on its Settings page. The gear on a grid opens the same editor for that grid.
Archived gridA grid taken out of use from its menu on the Grid Admin tab, without deleting it: listed under Archived grids in the Grids page's side navigation, refused by the pages that show it, and restored from there. Deleting it for good is done in Setup.
Grid Guide tabThis guide. Everyone with Rowhouse Grid User can open it in the Rowhouse app, from the App Launcher or from Help (?) on a grid; its pages for admins show to Rowhouse Grid Admin.
Rowhouse appThe Lightning app, with the Rowhouse logo, that holds the Grid Guide (where it opens), Grid Admin and Grid Edit Logs tabs. Rowhouse Grid User shows it with the Grid Guide only; Rowhouse Grid Admin adds the other two.
Rowhouse GridThe Lightning component you drag onto a page in Lightning App Builder.
Unsaved editA change shown in its cell, shaded yellow, not yet saved to Salesforce.
Save barThe light-blue bar that floats at the bottom of the grid while something is unsaved: the count of unsaved changes, and under it Undo, Redo, Cancel and Save.
RangeA rectangle of cells selected with Shift, for copy, paste, fill down and clear.
Row numberA row's place in the list, 1, 2, 3 down the grid's left edge, as in a list view. Not a record number: sorting or searching numbers the rows again. A row with errors shows its error icon just before it.
Selected rowsRows selected in the checkbox column, for Update field, Delete and actions, and an edit to every selected row (Update N selected items).
Row menuThe ▾ at a row's end: Edit, Delete and Change Owner, as on a list view, then the admin's actions.
ChartsThe toolbar's chart icon, which opens a chart of every matching record beside the grid.
New rowA row that New adds at the top of the grid, marked New where a row number goes. It is not a record until Save creates it; Undo or Cancel takes it away.
Display ruleA highlight (a color, bold, an icon or a data bar) that shows when a field meets a test or a formula is true, explained in the Display Key.
Display KeyThe swatch icon in a grid's toolbar, after Charts where the grid has them, that opens a key of what each display rule's look means.
Grid FilterA condition every row of a grid must meet, set by the admin, shown to users as a locked chip.
Formula columnA column the grid works out from other fields, in the syntax of a formula field. Read-only.
Field of a related recordA column for a field of the record a lookup points to, such as Account.Industry on a contact, headed Account: Industry. Changing it changes that record, on every row that shares it.
Record Page FieldOn a Grid Configuration, the lookup that links the grid's records to the record page it is placed on.
Grid User LayoutThe private record that keeps one user's layout of one grid; Reset layout deletes it.
Group, subtotal, Total rowRows gathered by a column's value, with figures for each group; the Total row covers the whole list.
Child tableA tab of related records under a row, itself a full grid.
ActionA flow or quick action run from a row's menu, or a flow run on the selected rows.
Grid Edit LogWhere the audit trail is kept, one entry per change, when a grid has Log Changes selected. Entries are kept forever unless an admin chooses a period on the Grid Admin tab; then a clean-up deletes older ones each night.
Rowhouse SettingThe one record, named Default, of settings for Rowhouse as a whole: for now, how long Grid Edit Log keeps its entries. Set on the Grid Admin tab's Settings page.
Rowhouse Grid User · Diagnostics · AdminThe three permission sets: the first for everyone who uses a grid, the second for troubleshooting, the third for whoever builds grids.
