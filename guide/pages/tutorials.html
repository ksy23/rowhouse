Before you start any of them

You need the Rowhouse Grid User permission set (see Give people access). We also recommend Rowhouse Grid Diagnostics while you build: if you mistype a setting, the grid tells you which and why. The first four build their grids in Setup, record by record, so you see every field; the last builds its grid on the Grid Admin tab, which makes the same records for you (see Your first grid). The tutorials use the sample records that come with a Developer Edition org, plus a few open deals and cases; in your org, use your own records wherever a step names one of ours.
