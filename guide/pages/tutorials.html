Before you start any of them

To use the grids you need the Rowhouse Grid User permission set; to build them, Rowhouse Grid Admin too, and Customize Application to save (see Give people access). Rowhouse Grid Admin also shows what Rowhouse Grid Diagnostics shows: if you mistype a setting, the grid tells you which and why. Four tutorials build their grids in Setup, record by record, so you see every field: the contact clean-up, key accounts, the pipeline review and the morning triage. The other four build theirs on the Grid Admin tab, which makes the same records for you (see Your first grid). To skip the build, each tutorial has a Skip the build box under What you will build: its button builds that tutorial's grids in a few seconds, and you go on to the step that puts the grid on a page. Each tutorial stands on its own: start with any of them. The tutorials use the sample records that come with a Developer Edition org, plus a few open deals, cases and contacts of our own; in your org, use your own records wherever a step names one of ours.
